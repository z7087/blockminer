# BlockMiner

可以帮助破坏一些生存模式下不可破坏的方块的客户端mod

# 使用须知

此 mod 大量使用原版 Minecraft 客户端不可能做到的操作完成破坏方块，因此可能在绝大多数服务器内被视为外挂。  
请遵守服务器规则游玩，使用本 mod 前先询问服务器管理员和其他玩家的意见。对于因使用本 mod 造成财产损失和人员伤亡的，制作者不承担任何责任。

# 说明

此 mod 支持使用红石火把或拉杆这两种方案破坏方块。

#### 破坏方块默认白名单（可作为此 mod 破坏方块的目标）：
- 基岩
#### 依赖方块默认白名单（可为能源方块提供支撑）：
- 粘液块
#### 需求：
必需： 活塞 * 2 + 红石火把或拉杆 * 1 + 效率 5 铁镐（或更高材质，仅对于红石火把方案）  
可选： 依赖方块默认白名单内方块 | 信标提供的急迫效果（挖活塞挖得更快）  
建议安装但可选模组： fabric-api（不装用不了命令、看不了i18n文本）

# 使用方法

空手右键点击基岩启动或关闭此 mod  
启动后，对破坏方块默认白名单内方块左键点击，此 mod 会尝试破坏那个方块
